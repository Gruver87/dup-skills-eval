# Start here (plain language)

**What:** fail-closed **eval gate** for Agent Skills (static checks + honesty rules).  
**Not:** a marketplace score that guarantees safety forever.

```powershell
cd dup-skills-eval
python -m pip install -e ".[dev]"
.\scripts\demo.ps1   # or: make demo
```

Beginners: start from [`dup-lab`](https://github.com/Gruver87/dup-lab) bootstrap — this package is pulled in automatically.
